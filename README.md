# Hushland · 星野

A quiet place under a real night sky. Walk around, sit by the fire, or become a blade of grass or a tree and watch the stars with whoever else is here.

- Front end: three.js r128, single `index.html`, textures in `tex/`
- Multiplayer: Supabase Realtime presence (fill in `XY_CONFIG` at the top of `index.html`)
- Star catalog derived from d3-celestial data (BSD-3)

Built by Jiayu Shao with Claude.
